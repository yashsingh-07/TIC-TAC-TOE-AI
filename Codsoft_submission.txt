Project Description

I developed a Python-based Tic-Tac-Toe game in which a human player competes against an AI agent.

The AI uses the Minimax algorithm to evaluate possible game states and select the optimal move. The objective is to create an AI opponent that plays intelligently and cannot be defeated when the algorithm is used correctly.

Main Features

- Human vs AI gameplay
- AI decision-making using Minimax
- Unbeatable AI strategy
- Win detection
- Draw detection
- Invalid input handling
- Replay option
- Command-line interface
- No external Python dependencies

Technologies Used

- Python 3
- Minimax algorithm
- "math" standard library
- Functions
- Lists
- Loops
- Conditional statements
- Recursion

How the AI Works

The AI uses the Minimax algorithm.

For every available move, the AI simulates possible future game situations and evaluates the resulting outcomes.

The algorithm assigns higher scores to AI wins, lower scores to human wins, and a neutral score to draws.

The AI then selects the move with the best possible outcome.
